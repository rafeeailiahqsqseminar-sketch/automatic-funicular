SKRIP TELEPROMPTER — KENAPA KITA JATUH CINTA?
(lebih kurang 70 saat · baca perlahan · / = jeda pendek · // = jeda panjang · HURUF BESAR = tekan)

---

Korang pernah tak... /
jumpa seseorang, /
dan tiba-tiba hati rasa /
"dia lah orangnya"? //

Sebenarnya... /
yang pilih dulu /
bukan HATI. /
Tapi OTAK. //

Ada TIGA sebab. //

SATU. /
Selalu NAMPAK, jadi SAYANG. /
Makin kerap kita jumpa seseorang, /
makin selesa kita dengan dia. /
Sebab itu ramai jatuh cinta /
dengan kawan sekelas, /
atau rakan sekerja. //

DUA. /
Kita suka orang /
yang SAMA dengan kita. /
Cara cakap sama. /
Nilai hidup sama. /
Otak rasa SELAMAT. /
Dan rasa selamat itu... /
kita panggil cinta. //

TIGA. /
Kita cari rasa /
yang kita kenal masa KECIL. /
Cara mak ayah sayang kita dulu, /
itulah "rasa cinta" /
yang otak kita cari semula. //

Jadi kalau korang /
asyik jatuh cinta /
dengan orang yang SAMA jenis... /
mungkin bukan nasib. /
Mungkin itu CORAK. //

Kenal diri dulu. /
Baru kenal /
siapa yang layak. //

Saya Rafee Ailiah. /
Nak faham diri lebih dalam? /
Bergabung bersama komuniti kami. /
