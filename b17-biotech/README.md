# B17 Biotech HQ

Buka aplikasi: https://claude.ai/artifact/7kvFKxbCNKpiHmLGksnpSS

Aplikasi web satu fail untuk CEO B17 Biotech:

- **Papan CEO**: KPI, carta hasil, saluran produk R&D, aktiviti terkini.
- **Pekerja AI**: 3 pekerja AI (AIRA – R&D, NIKO – Operasi, QC & NPRA, SERA – Pencari Idea Konten). Boleh berbual, minta laporan, dan beri tugasan dengan `/tugas tajuk`.
- **Pejabat Maya**: pelan lantai masa nyata; avatar bergerak ke bilik mesyuarat atau pantri.
- **Idea Konten**: SERA cari idea konten (TikTok, Reels, Shorts, dll). Idea boleh disimpan, dijadikan tugasan, dan SERA tulis skrip siap rakam.
- **Tugasan**: papan Kanban (Baharu → Sedang dibuat → Semakan CEO → Siap), seret-lepas, tapis, cari, lulus atau minta pembetulan.

Buka `index.html` terus dalam pelayar. Data disimpan dalam `localStorage` pelayar. Angka kewangan dan saluran produk ialah data contoh.

Bila dibuka di claude.ai, 3 pekerja AI dijawab oleh Claude sebenar (guna kuota Claude pengguna): berbual, cipta tugasan sendiri, dan tulis laporan "Hasil kerja". Di luar claude.ai, mereka guna jawapan tetap.
